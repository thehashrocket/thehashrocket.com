# Domain Context — thehashrocket.com

## Who

Jason Shultz is a senior full-stack software engineer with 14 years of experience. He builds complex, high-stakes systems across industries including pharmaceutical logistics, nonprofit technology, and AI-powered data discovery.

## What This Site Is

A creative developer portfolio that doubles as a portfolio piece itself. The site converts potential consulting/freelance clients by demonstrating both technical craft (immersive 3D, scroll-driven narratives) and real-world project impact.

## Business Model

- Solo consulting/freelance engineering
- Target clients: startups and enterprises with complex operational software needs
- Positioning: premium (budget range starts at $10k)
- Primary conversion: contact form inquiry

## Project Domains

The portfolio showcases three projects, each in a different serious domain:

1. **Pharma WMS** — Warehouse management for pharmaceutical distribution. Operations, logistics, compliance.
2. **Nonprofit Matching** — Connecting donors with organizations through intelligent matching. Network graphs, relationship modeling.
3. **Grant Discovery** — AI-powered grant matching and application tracking. Data pipelines, LLM integration.

Case study content (descriptions, tech stacks, narratives) lives in `app/work/[slug]/page.tsx`. This file is the source of truth for project details — do not duplicate here.
